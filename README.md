# KinectAnimationStudio-Remaster

![image alt](https://github.com/SevenAnims/Kinect-Animation-Studio-Remaster/blob/main/images/Capture%20d'%C3%A9cran%202026-10-19%20150039.png)

__Kinect Animation Studio Remaster exports Kinect V2 skeleton data as FBX motion files. Ideal for animating 3D models.__

* No installation.
* Works with live capture or pre-recorded data (through Kinect Studio)
* Straightforward use. Does not require setting additional parameters.

## System Requirements ( not including build requirements )

*Using VibeCoding via OpenCode

* [Originale Work](https://github.com/marcojrfurtado/KinectAnimationStudio) by [marcojrfurtado](https://github.com/marcojrfurtado)

* Windows 8 or later
* 64-bit (x64) processor
* [Kinect SDK V2.0](http://www.microsoft.com/en-ca/download/details.aspx?id=44561)

See [this page](http://marcojrfurtado.github.io/KinectAnimationStudio) for more info and build instructions.
